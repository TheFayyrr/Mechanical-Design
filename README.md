## 打开动画

下载此仓库（Code → Download ZIP），解压后用 Chrome、Edge 或 Safari 打开 `齿轮gear/动画/index.html`。不需要安装依赖或启动服务器。GitHub 文件预览页只显示源码，不会执行动画。
