# 01 基础概念与四个圆

## 1. 一个齿轮为什么需要几个不同的圆

真实齿轮只有材料边界，教材中的圆大多是计算用的几何线。同一齿轮上，不同的圆承担不同任务。

| 名称 | 符号 | 含义 | 是否由另一只齿轮的安装位置决定 |
|---|---|---|---|
| 分度圆 | d、r | 定义标准模数、压力角等参数的参考圆 | 否 |
| 基圆 | db、rb | 生成渐开线齿廓的圆 | 否 |
| 齿顶圆 | da、ra | 通过轮齿顶端 | 否 |
| 齿根圆 | df、rf | 通过齿槽底部 | 否 |
| 节圆 | dw、rw，课件也用 d′、r′ | 配对传动时具有相同瞬时传动比的纯滚动圆 | 是 |

“圆的直径”与“半径”不能混用：d＝2r。基圆不等于齿根圆。分度圆一般不是齿高的正中间，因为正常齿制齿顶高 m、齿根高 1.25m。

## 2. 分度圆究竟怎样得到

沿任意同心圆测量相邻同侧齿廓的圆弧间距，其值都随半径变化。设计需要统一参考，因此指定一个圆，在其上规定模数、压力角和齿厚等参数，这就是分度圆。

在分度圆上，一段齿厚 s 加一段齿槽宽 e，构成一个齿距 p。齿数 z 个齿距铺满整个圆周：

πd＝zp。

定义模数 m＝p/π，则 d＝mz。

实际设计先按承载、尺寸和传动比等需求选模数及齿数，再得到参考直径；不是先让线头运动、再把经过的某个位置认作分度圆。模数由标准系列选取，齿数由设计确定，不是唯一的标准常数。

## 3. 五个基本参数

| 参数 | 含义 | 本文标准正常齿制取值 |
|---|---|---|
| m | 模数，反映轮齿大小，单位 mm | 标准系列中选取 |
| z | 齿数 | 按设计选取正整数 |
| α | 分度圆压力角 | 20° |
| ha* | 齿顶高系数 | 1 |
| c* | 顶隙系数 | 0.25 |

“标准值”分两种：m 有多个标准数值，后三项是在本齿制下采用的指定值。不能说所有齿轮压力角、齿高都只能使用这一组数值。

同模数齿数越多，分度圆越大；同齿数模数越大，齿轮与轮齿都变大。

## 4. 标准未变位直齿外齿轮的尺寸

适用前提：本文标准正常齿制、未变位、未修薄的理想几何。

| 量 | 公式 |
|---|---|
| 分度圆直径 | d＝mz |
| 基圆直径 | db＝d cosα |
| 齿顶高 | ha＝m |
| 齿根高 | hf＝1.25m |
| 全齿高 | h＝2.25m |
| 齿顶圆直径 | da＝d＋2ha＝m(z＋2) |
| 齿根圆直径 | df＝d－2hf＝m(z－2.5) |
| 分度圆齿距 | p＝πm |
| 分度圆齿厚、齿槽宽 | s＝e＝πm/2 |
| 基节 | pb＝πm cosα |
| 标准中心距，外啮合 | a＝m(z₁＋z₂)/2 |

齿厚 s 和齿槽宽 e 是对应圆上的弧长，不是两点间的直线距离。真实制造常通过齿厚公差等保证侧隙，不能把理想 s＝e 当作实物绝无间隙。

## 5. 为什么留顶隙

轮齿通过侧面推另一轮的齿侧。一颗齿进入对方齿槽时，齿尖不能顶到槽底。

标准安装时 c＝hf－ha＝0.25m。它避免齿顶与齿根底部碰撞，并留出润滑和一定误差余量。

顶隙与侧隙不同：顶隙在齿尖与槽底之间；侧隙在非工作齿侧之间，与反向空程相关。不能用一个代替另一个。

## 6. 基圆、齿根圆谁大

db＝mz cosα，df＝m(z－2.5)。二者取决于 z。

α＝20°时，分界约为 z＝2.5/(1－cos20°)≈41.45：z≤41 时基圆较大，z≥42 时齿根圆较大。因此不能死记“基圆总在齿根圆外面”。渐开线只能从基圆向外生成，基圆内的齿根部分是过渡轮廓。
