## 动画怎么观察

| 主题 | 先看哪里 | 应该看懂什么 |
|---|---|---|
| 重合度与交接 | 右侧放大图中的同色轮齿和接触点 | 一对齿怎样进入、经过节点、退出；两对怎样重叠接班 |
| 四个圆 | 两个实际齿轮上的同心圆 | 分度圆是尺寸基准，基圆生成齿形，齿顶圆经过齿尖，齿根圆经过槽底 |
| 渐开线与压力角 | 绷紧的 BP 与线头 P | BP 始终与基圆相切；OP 变长；到分度圆只是经过，不是停止条件 |
| 分度圆与节圆 | 增加中心距前后的圆和接触区 | 分度圆、基圆不变；节圆、工作压力角和重合度改变 |

点击播放或拖动进度均可。动画播放三次齿对交接后停止，可重播。不同主题使用同一个几何模型。渐开线生成是单齿侧的几何演示，其余主题均直接显示齿轮。

## 你此前的问题，对应到哪里

- “分度圆怎么得到？”：01 的齿距定义与设计基准。
- “基圆怎么确定？”：02 的 db＝mz cosα。
- “OP 要相切才停止吗？”：02 的 BP/OP 区分。
- “P 到达分度圆怎么判断？”：02 的 OP＝mz/2。
- “为什么留顶隙？”：01 的齿顶与齿槽底部间隙。
- “重合度到底重合什么？”：03 的齿对交接和时间比例。
- “基节与齿距有什么不同？”：03 的沿基圆、沿啮合线、沿分度圆三种测量。

## 模型边界

实际工作齿侧按渐开线计算。齿根连接简化，不用于加工。高亮表示几何接触，不能用颜色判断每对齿承担的力。ε＜1 的方案仅展示几何空档，两轮仍按理想速比运动，不代表真实断续传动的动力学。
