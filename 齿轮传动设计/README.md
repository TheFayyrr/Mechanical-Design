# 齿轮传动设计：第11章入门笔记

依据用户提供的《第11章 齿轮传动n.pptx》68张幻灯片整理。重点区分“能否按速比运动”和“能否承受载荷”。本篇按课件主题概括；图片中的材料表、复杂公式和标准条款未逐项转录，不作为完整工程选型依据。

## 1. 五种失效与对策（第5～12页）

| 失效 | 原理 | 改进方向 |
|---|---|---|
| 轮齿折断 | 齿根弯曲疲劳、应力集中或过载冲击 | 合理增大模数、改善齿根过渡、提高材料与加工质量 |
| 齿面点蚀 | 反复接触应力造成表层疲劳剥落 | 提高接触承载能力、改善硬度和润滑 |
| 齿面胶合 | 油膜失效，局部黏着后被滑动撕裂 | 合适润滑、散热、表面质量及载荷控制 |
| 齿面磨损 | 污染颗粒与滑动使齿廓逐渐损失 | 密封、过滤、润滑与耐磨材料 |
| 塑性变形 | 材料过软或载荷过大，表面材料流动 | 提高硬度、控制载荷、改善润滑 |

课件的传统设计次序：闭式软齿面先按接触强度设计、再校核弯曲；闭式硬齿面先按弯曲设计、再校核接触；开式主要关注磨损与弯曲。这里是课程分类，不意味着某一类只可能发生一种失效。

课件对开式传动给出模数增加10%～15%的经验处理，应理解为课程方法，不能替代具体磨损工况判断。

## 2. 材料与热处理（第14～17、38页）

目标是齿面具有耐磨、抗接触疲劳能力，芯部保持韧性。常见钢、铸铁、铸钢及工程塑料需要按载荷、尺寸、速度、制造方式选择。

正火、调质常用于课程中的软齿面方案；表面淬火、渗碳淬火、渗氮用于提高表面性能。不同材料适用的热处理不同。课件软齿面配对建议小轮较大轮硬30～50 HBW，是考虑小轮循环次数等的课程经验。

## 3. 精度（第19页）

关注运动准确性、传动平稳性和沿齿宽载荷分布。课件含精度等级与旧公差组表述；本文未核验其标准版本，不把这些表述当作现行标准条文。具体工程应按指定标准版本和检测项目执行。

## 4. 直齿外齿轮受力（第21～22页）

研究对象：单个齿轮。外力包括齿面接触力及轴传来的支承、驱动或阻力矩。忽略摩擦时，接触力 Fn 沿公法线。

Ft＝2T/d；Fr＝Ft tanα；Fn＝Ft/cosα；理想直齿轮 Fa＝0。

主动轮受到的齿面切向力与该点速度方向相反，从动轮与其速度方向相同；外啮合径向分力指向各自轮心。两轮接触力满足作用与反作用，方向相反。

T 用 N·m 时 d 用 m；T 用 N·mm 时 d 用 mm。计算载荷引入载荷系数 K，反映冲击、制造和安装误差等影响，不能凭空假定实际机器一定取某一数值。

## 5. 接触强度与弯曲强度（第24～36页）

接触强度控制齿面疲劳点蚀，以赫兹接触理论为基础。常见外啮合计算结构：

σH＝ZH ZE Zε √[K Ft (u＋1)/(b d₁ u)]，其中系数定义必须采用同一教材/标准体系，不能混用数值。

弯曲强度把轮齿视作短悬臂，控制齿根疲劳折断。课程常见计算结构：

σF＝K Ft YFa YSa/(b m)。

两轮齿数、齿形系数及许用应力可能不同，需要分别判断弯曲危险性。接触应力相同也不代表两轮许用应力相同。

材料疲劳极限、安全系数、寿命修正、齿形系数等需要查对应资料。这里解释公式结构，不给出虚构查表值。详细课程公式中的合并系数待按原图逐项核对后补充。

## 6. 参数选择与设计流程（第38～42页）

明确功率、转速、速比、寿命和工况；选择材料及热处理；初选齿数、精度、齿宽系数；按主要失效设计；选标准模数并圆整；校核另一种强度；检查几何、干涉、润滑、结构和装配。

增大齿宽能降低平均载荷，但可能加重偏载，对轴和支承刚度提出要求，不能无限加宽。较宽小轮可以提供装配余量，有效接触宽度由实际重叠宽度决定。

第42页几何训练的一组答案见[齿轮例题5](../齿轮gear/笔记/05-例题与自测.md)。

## 7. 斜齿轮（第44～48页）

Ft＝2T/d；Fr＝Ft tanαt＝Ft tanαn/cosβ；Fa＝Ft tanβ。

切向、径向方向与外啮合直齿类似，轴向方向还取决于旋向和转向。必须先标研究对象、轴线与转向，再使用一致的左右手判别约定；不要只凭纸面上的斜线方向猜测旋向。

当量齿数 zv＝z/cos³β 用于法面齿形的近似计算。斜齿强度不能只把直齿公式里的 m 随意换成 mn，需采用完整对应系数体系。

## 8. 直齿锥齿轮（第50～54页）

常在齿宽中点用平均分度圆直径 dm：Ft＝2T/dm，Fr＝Ft tanα cosδ，Fa＝Ft tanα sinδ。δ是该轮分度圆锥角。径向、轴向方向应结合锥顶和大端位置判断。

课程按齿宽中点当量齿轮近似计算强度。空间受力和锥角关系将在独立专题中展开。

## 9. 构造、润滑、效率（第56～64页）

齿轮轴、实心式、腹板式、轮辐式的选择与尺寸、键槽处厚度、重量和制造方法有关。课件尺寸界限是教学经验，不是任意材料、任意工况都适用的强制分界。

闭式传动可浸油或喷油，开式可按工况加油或使用适宜润滑脂。实际选择需结合圆周速度、温升、负载和油品要求，不能只按一个速度阈值决定。

损耗包括齿面摩擦、搅油和轴承摩擦。T输出＝ηiT输入，P输出＝ηP输入。效率取决于系统边界，不能把单级啮合效率直接当作整个减速器效率。

## 10. 圆弧齿轮（第66～68页）

使用凸、凹圆弧配对改善接触条件，通常依靠斜齿形式提供轴向接触重叠。与渐开线齿轮相比，其对中心距和加工安装的敏感性不同。课件给出的承载倍率属于特定比较，本文不将其作为所有产品的通用性能保证。
