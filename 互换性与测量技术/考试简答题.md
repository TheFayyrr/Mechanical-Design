**一、论述题**

**1．滚动轴承与轴、外壳孔配合，采用何种基准制？**

答案：

- 轴承内圈内孔与轴配合：采用**基孔制**。
- 轴承外圈外径与外壳孔配合：采用**基轴制**。

原因：轴承是标准件，其内径、外径公差带已经确定，通过改变轴或外壳孔的公差带获得不同配合。

注意：**轴承内孔公差带具有特殊性，不能直接当作普通 H 孔。**

知识点：基准制、标准件配合、轴承配合。

**2．平键连接、花键连接采用何种基准制？**

答案：

- 平键连接的键宽配合：采用**基轴制**。以键宽为基准，改变轴槽、轮毂槽宽度的公差带。
- 花键连接：通常采用**基孔制**，通过改变外花键公差带获得不同配合。

知识点：键连接、花键连接、基准制选择。

**3．何谓螺纹中径、顶径和底径？**

| 名称 | 定义 |
|---|---|
| 中径 | 一个假想圆柱的直径，该圆柱母线经过牙型上牙厚与牙槽宽度相等的位置 |
| 顶径 | 与螺纹牙顶相切的假想圆柱直径 |
| 底径 | 与螺纹牙底相切的假想圆柱直径 |

对应关系：

- 外螺纹：顶径是大径，底径是小径。
- 内螺纹：顶径是小径，底径是大径。

知识点：螺纹几何参数。**不要把“顶径”一律理解成“大径”。**

**4．齿轮传动的四项使用要求是什么？不同用途侧重点是否不同？**

| 使用要求 | 含义 | 典型侧重点 |
|---|---|---|
| 传递运动的准确性 | 实际转角与理论转角的误差小 | 分度机构、精密传动 |
| 传动平稳性 | 瞬时传动比波动小，冲击和噪声小 | 高速齿轮 |
| 载荷分布均匀性 | 齿面接触良好，避免局部载荷集中 | 重载齿轮 |
| 合理的齿侧间隙 | 保证润滑、补偿热变形，并满足回程要求 | 普通动力传动需适当间隙，精密反向传动需控制回程间隙 |

答案：**不同用途、工况的侧重点不同。**

知识点：齿轮精度与功能要求。

**五、简答题**

**1．什么叫互换性？有什么作用？**

同一规格的一批零部件，在规定范围内任取一个，不需附加修配即可装配，并满足使用要求，称为具有互换性。

作用：

- 设计：便于采用标准件、通用件，缩短设计周期。
- 制造：便于专业化、批量化生产，提高装配效率。
- 维修：便于更换损坏零件，降低维修时间与费用。

**2．什么是基孔制、基轴制？为什么规定基准制？为什么常用基孔制？何时用基轴制？**

- 基孔制：固定基准孔公差带，通过改变轴公差带形成不同配合；基准孔为 H，EI＝0。
- 基轴制：固定基准轴公差带，通过改变孔公差带形成不同配合；基准轴为 h，es＝0。
- 规定基准制：减少刀具、量具和公差带规格，取得技术经济效益。
- 常用基孔制：孔加工经常使用钻头、铰刀、塞规等定尺寸工具，固定孔尺寸更经济。
- 采用基轴制：使用冷拉钢材直接作轴；同一轴径与多个孔形成不同配合；以标准外径件为配合基准等。

**3．什么是最大、最小实体尺寸？与极限尺寸的关系？**

最大实体尺寸：零件在允许范围内材料量最多时的尺寸。

最小实体尺寸：零件在允许范围内材料量最少时的尺寸。

| 对象 | 最大实体尺寸 | 最小实体尺寸 |
|---|---|---|
| 孔 | 最小极限尺寸 | 最大极限尺寸 |
| 轴 | 最大极限尺寸 | 最小极限尺寸 |

记忆：**孔越小，剩下的材料越多；轴越大，材料越多。**

**4．公差与偏差的区别和联系？**

| 对比项 | 偏差 | 公差 |
|---|---|---|
| 定义 | 某尺寸减基本尺寸所得的代数差 | 允许尺寸变动的范围 |
| 正负号 | 可正、可负、可为零 | 为正值 |
| 作用 | 表示尺寸偏离基本尺寸的位置 | 表示尺寸控制的宽严 |
| 联系 | 孔公差＝ES－EI；轴公差＝es－ei | 等于上、下偏差之差 |

**5．粗糙度轮廓的三个主要评定参数及定义？**

**五、简答题**

**1．基孔制、基轴制定义，何时采用基轴制？**

答案：

- 基孔制：以 H 孔为基准，通过改变轴公差带获得不同配合。
- 基轴制：以 h 轴为基准，通过改变孔公差带获得不同配合。

适合基轴制的情况：

1. 冷拉钢材不再加工直接作轴。
2. 同一尺寸轴段上与多个孔形成不同配合。
3. 与外径已经确定的标准件配合，例如轴承外圈与外壳孔。

**2．普通螺纹公差带有什么特点？**

答案：

1. 以基本牙型轮廓为零线，呈牙型带状分布。
2. 公差带大小由公差等级确定，位置由基本偏差确定。
3. 内螺纹常见基本偏差为 G、H；外螺纹常见基本偏差为 e、f、g、h。
4. 中径公差带与顶径公差带可以采用不同等级。
5. 中径公差还要综合考虑螺距、牙侧角误差对旋合的影响。
6. 螺纹精度选择与旋合长度有关。

**3．选择轴承与轴、外壳孔的配合，主要考虑什么？**

| 因素 | 对配合选择的影响 |
|---|---|
| 套圈相对于载荷的运动情况 | 承受旋转载荷的套圈通常需要较紧配合，防止爬动 |
| 载荷大小、冲击振动 | 载荷越重、冲击越明显，通常需要更可靠的过盈 |
| 转速与旋转精度 | 高速、高精度场合要兼顾定心与变形 |
| 温度 | 温差会改变实际过盈和轴承内部游隙 |
| 轴与座孔的材料、刚度 | 薄壁、空心结构或轻合金座会影响配合效果 |
| 装拆要求 | 频繁拆卸时要兼顾可维护性 |
| 游动端安排 | 需要轴向移动的套圈，不能不加分析地采用过紧配合 |

**不是“内圈永远过盈、外圈永远间隙”，而是先判断套圈相对于载荷的运动。**

**4．什么是未注公差尺寸？适用什么情况？公差如何规定？**

答案：

未注公差尺寸是**没有逐个标出极限偏差，但仍应满足图样统一规定的一般公差的尺寸**。

适用情况：功能上没有特殊精度要求，正常工艺能够保证的尺寸。

本题按一般公差的常见教学口径：

- 等级分为 f、m、c、v，即精密、中等、粗糙、最粗。
- 通常采用相对于公称尺寸对称的正负偏差。
- 具体偏差值根据尺寸段和选定等级查表。
- 在图样技术要求或标题栏附近统一说明。

注意：**f、m、c、v 不是 IT6、IT7 这样的标准公差等级。**

**四、2013 年秋季 B 卷：填空题**

**1．公差标准是对______的限制性措施，______是贯彻公差与配合制的技术保证。**

**答案：加工误差；技术测量。**

**2．实际偏差是指______，极限偏差是指______。**

**答案：实际尺寸与基本尺寸的代数差；极限尺寸与基本尺寸的代数差。**

**3．孔和轴的公差带由______决定大小，由______决定位置。**

**答案：标准公差；基本偏差。**

**4．圆柱度和径向全跳动公差带相同点是______，不同点是______。**

**答案：**

- 相同点：**形状相同，均为半径差为公差值 t 的两同轴圆柱面之间的区域。**
- 不同点：**圆柱度公差带的轴线可以浮动；径向全跳动公差带的轴线由基准轴线确定。**

**5．在形状公差中，当被测要素是一空间直线，若给定一个方向时，其公差带是______之间的区域。若给定任意方向时，其公差带是______区域。**

**答案：间距为公差值 t 的两平行平面；直径为公差值 t 的圆柱面内的。**

填入后：

- 给定一个方向：公差带是**间距为 t 的两平行平面之间的区域**。
- 任意方向：公差带是**直径为 t 的圆柱面内的区域**。

注意：题目特指**空间直线**，不要与平面内直线的“两平行直线之间”混淆。

**6．圆度的公差带形状是______，圆柱度的公差带形状是______。**

**答案：**

- 圆度：**同一平面内，半径差为公差值 t 的两同心圆之间的区域。**
- 圆柱度：**半径差为公差值 t 的两同轴圆柱面之间的区域。**

**7．孔和轴的公差带由______决定大小，由______决定位置。**

**答案：标准公差；基本偏差。**

原卷这一题与第 3 题重复。

**8．公差带的位置由______决定，公差带的大小由______决定。**

**答案：基本偏差；标准公差。**

注意：本题顺序与第 3、7 题相反。

**9．实际偏差是指______，极限偏差是指______。**

**答案：实际尺寸与基本尺寸的代数差；极限尺寸与基本尺寸的代数差。**

原卷这一题与第 2 题重复。

**10．由于______包括了圆柱度误差和同轴度误差，当______不大于给定的圆柱度公差值时，可以肯定圆柱度误差不会超差。**

**答案：径向全跳动误差；径向全跳动误差。**

填入后：

由于**径向全跳动误差**包括了圆柱度误差和同轴度误差，当**径向全跳动误差**不大于给定的圆柱度公差值时，可以肯定圆柱度误差不会超差。

这里的“包括”表示**综合控制作用**，不是说“径向全跳动误差＝圆柱度误差＋同轴度误差”。
